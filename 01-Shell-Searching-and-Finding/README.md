# Shell Searching and Finding

[Back to the repository index](../README.md)

These scripts use standard Unix commands to locate files and count directory entries.

| Exercise | Script | What it demonstrates |
| --- | --- | --- |
| [ex0](ex0/find_sh.sh) | `find_sh` | Finds files ending in `.sh` and prints their base names without the extension. |
| [ex2](ex2/count_files.sh) | `count_files` | Counts the entries listed by `find`, including the starting directory. |
