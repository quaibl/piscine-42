# Git Fundamentals

[Back to the repository index](../README.md)

These scripts inspect a repository’s commit history and ignored files.

| Exercise | Script | What it demonstrates |
| --- | --- | --- |
| [ex0](ex0/git_commit.sh) | `git_commit` | Prints the full hashes of up to five recent commits. |
| [ex1](ex1/git_ignore.sh) | `git_ignore` | Lists ignored, untracked files using Git’s standard ignore rules. |
