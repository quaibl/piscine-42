# C Programming Fundamentals

[Back to the repository index](../README.md)

These exercises practice character output, loops, and conditions.

| Exercise | Function | What it demonstrates |
| --- | --- | --- |
| [ex0](ex0/ft_putchar.c) | `ft_putchar` | Writes a single character to standard output. |
| [ex1](ex1/ft_print_alphabet.c) | `ft_print_alphabet` | Prints the lowercase alphabet from `a` to `z`. |
| [ex2](ex2/ft_print_reverse_alphabet.c) | `ft_print_reverse_alphabet` | Prints the lowercase alphabet from `z` to `a`. |
| [ex3](ex3/ft_print_numbers.c) | `ft_print_numbers` | Prints the digits from `0` to `9`. |
| [ex4](ex4/ft_is_negative.c) | `ft_is_negative` | Prints `N` for a negative integer and `P` otherwise. |
