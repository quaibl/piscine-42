# C Characters and Arithmetics

[Back to the repository index](../README.md)

These exercises turn numbers into characters and use arithmetic to enumerate digit combinations.

| Exercise | Function | What it demonstrates |
| --- | --- | --- |
| [ex0](ex0/ft_putnbr.c) | `ft_putnbr` | Prints a signed integer in decimal. |
| [ex1](ex1/ft_print_comb.c) | `ft_print_comb` | Prints combinations of three distinct digits in increasing order. |
| [ex2](ex2/ft_print_comb2.c) | `ft_print_comb2` | Prints pairs of distinct two-digit numbers from `00` to `99` in increasing order. |
