# C Algorithmics Fundamentals

[Back to the repository index](../README.md)

These exercises compare loops and recursion for basic numerical algorithms.

| Exercise | Function | What it demonstrates |
| --- | --- | --- |
| [ex0](ex0/ft_iterative_factorial.c) | `ft_iterative_factorial` | Computes a factorial with a loop. |
| [ex1](ex1/ft_recursive_factorial.c) | `ft_recursive_factorial` | Computes a factorial recursively. |
| [ex2](ex2/ft_iterative_power.c) | `ft_iterative_power` | Raises an integer to a power with a loop. |
| [ex3](ex3/ft_recursive_power.c) | `ft_recursive_power` | Raises an integer to a power recursively. |
| [ex4](ex4/ft_fibonacci.c) | `ft_fibonacci` | Computes a Fibonacci number by index. |
