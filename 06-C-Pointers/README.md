# C Pointers

[Back to the repository index](../README.md)

These exercises show how C functions use addresses to modify variables, return multiple results through output parameters, and work with arrays in place.

| Exercise | Function | What it demonstrates |
| --- | --- | --- |
| [ex0](ex0/ft_ft.c) | `ft_ft` | Sets an integer to 42 through a pointer. |
| [ex1](ex1/ft_ultimate_ft.c) | `ft_ultimate_ft` | Sets an integer to 42 through nine levels of indirection. |
| [ex2](ex2/ft_swap.c) | `ft_swap` | Exchanges the values stored at two addresses. |
| [ex3](ex3/ft_div_mod.c) | `ft_div_mod` | Stores the quotient and remainder in two output variables. |
| [ex4](ex4/ft_ultimate_div_mod.c) | `ft_ultimate_div_mod` | Replaces the two original values with the quotient and remainder. |
| [ex5](ex5/ft_rev_int_tab.c) | `ft_rev_int_tab` | Reverses an integer array in place. |
| [ex6](ex6/ft_sort_int_tab.c) | `ft_sort_int_tab` | Sorts an integer array in ascending order. |
