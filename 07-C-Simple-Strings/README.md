# C Simple Strings

[Back to the repository index](../README.md)

These exercises use the null terminator to scan, classify, transform, and print C strings.

| Exercise | Function | What it demonstrates |
| --- | --- | --- |
| [ex1](ex1/ft_str_is_numeric.c) | `ft_str_is_numeric` | Checks whether a string contains only decimal digits. |
| [ex2](ex2/ft_str_is_lowercase.c) | `ft_str_is_lowercase` | Checks whether a string contains only lowercase letters. |
| [ex3](ex3/ft_str_is_uppercase.c) | `ft_str_is_uppercase` | Checks whether a string contains only uppercase letters. |
| [ex4](ex4/ft_str_is_printable.c) | `ft_str_is_printable` | Checks whether a string contains only printable ASCII characters. |
| [ex5](ex5/ft_strupcase.c) | `ft_strupcase` | Converts lowercase letters to uppercase in place. |
| [ex6](ex6/ft_strlowcase.c) | `ft_strlowcase` | Converts uppercase letters to lowercase in place. |
| [ex7](ex7/ft_strcapitalize.c) | `ft_strcapitalize` | Capitalizes the first letter of each word and lowercases the remaining letters. |
| [ex8](ex8/ft_strlen.c) | `ft_strlen` | Counts the characters before the null terminator. |
| [ex9](ex9/ft_putstr.c) | `ft_putstr` | Writes a string to standard output. |
| [ex10](ex10/ft_putstr_non_printable.c) | `ft_putstr_non_printable` | Prints a string with hexadecimal escapes for non-printable characters. |
