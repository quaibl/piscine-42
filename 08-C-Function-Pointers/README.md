# C Function Pointers

[Back to the repository index](../README.md)

These exercises pass functions as arguments to apply operations, check conditions, and compare values.

| Exercise | Function | What it demonstrates |
| --- | --- | --- |
| [ex0](ex0/ft_foreach.c) | `ft_foreach` | Applies a callback to each element of an integer array. |
| [ex2](ex2/ft_any.c) | `ft_any` | Checks whether any string in a null-terminated array matches a predicate. |
| [ex3](ex3/ft_count_if.c) | `ft_count_if` | Counts the strings that match a predicate in an array of a given length. |
| [ex4](ex4/ft_is_sort.c) | `ft_is_sort` | Checks whether an integer array is sorted in either direction according to a comparator. |
