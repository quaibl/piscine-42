# C Memory Management

[Back to the repository index](../README.md)

These exercises allocate memory for arrays and strings, including results whose size depends on the input.

| Exercise | Function | What it demonstrates |
| --- | --- | --- |
| [ex1](ex1/ft_range.c) | `ft_range` | Allocates an integer array containing a range from the lower bound up to the upper bound, exclusive. |
| [ex2](ex2/ft_ultimate_range.c) | `ft_ultimate_range` | Returns the length of an allocated integer range and passes the array back through an output pointer. |
| [ex3](ex3/ft_strjoin.c) | `ft_strjoin` | Joins strings into one allocated string with a separator between elements. |
| [ex4](ex4/ft_convert_base.c) · [helper](ex4/ft_convert_base2.c) | `ft_convert_base` | Converts a number represented in one base into a newly allocated string in another base. |
| [ex5](ex5/ft_split.c) | `ft_split` | Splits a string at delimiter characters and returns an allocated array of tokens. |
