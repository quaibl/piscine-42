# C System Interface

[Back to the repository index](../README.md)

These programs read and process command-line arguments through `argc` and `argv`.

| Exercise | Program | What it demonstrates |
| --- | --- | --- |
| [ex1](ex1/ft_print_params.c) | `ft_print_params` | Prints the arguments in their original order. |
| [ex2](ex2/ft_rev_params.c) | `ft_rev_params` | Prints the arguments in reverse order. |
| [ex3](ex3/ft_sort_params.c) | `ft_sort_params` | Sorts the arguments lexicographically before printing them. |
