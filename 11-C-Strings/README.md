# C Strings

[Back to the repository index](../README.md)

These exercises implement common C string operations and parse an integer from text.

| Exercise | Function | What it demonstrates |
| --- | --- | --- |
| [ex0](ex0/ft_strcpy.c) | `ft_strcpy` | Copies a null-terminated string into a destination buffer. |
| [ex2](ex2/ft_strcmp.c) | `ft_strcmp` | Compares two strings lexicographically. |
| [ex3](ex3/ft_strncmp.c) | `ft_strncmp` | Compares at most a specified number of characters from two strings. |
| [ex4](ex4/ft_strcat.c) | `ft_strcat` | Appends a string to the end of a destination string. |
| [ex5](ex5/ft_strncat.c) | `ft_strncat` | Appends at most a specified number of characters to a destination string. |
| [ex6](ex6/ft_strstr.c) | `ft_strstr` | Finds the first occurrence of a substring. |
| [ex7](ex7/ft_atoi.c) | `ft_atoi` | Parses an integer after leading whitespace and optional sign characters. |
